A deliberately small trust boundary

Local does not mean unauthenticated.

Every sensitive endpoint requires a scoped credential. Browser access begins with a short-lived code created by the person at the Windows machine.

01

Pair one origin

A 128-bit, five-minute code is bound to one exact HTTPS origin and consumed once. Browser tokens cannot be replayed by another site.

https://billing.example
02

Inspect the queue

Jobs have visible states, atomic claims, explicit cancellation, and at most three manual retries. Interrupted submissions become unknown.

queuedprintingterminal
03

Constrain the document

Static, unencrypted PDFs only. MIME, signature, pages, objects, streams, images, and active features are validated before queueing.

PrintLatch never fetches a URL, constructs a shell command, listens on the LAN, or routes a job through a PrintLatch server.

Honest V1 support

Useful now. Intentionally not universal.

The built-in PDF capture path is end-to-end testable without hardware. Physical output still depends on the installed Windows driver and printer.
