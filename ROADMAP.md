# Roadmap

Roadmap items are evidence gates, not promises.

## 0.1

- Windows 11 x64
- static PDF only
- exact-origin browser pairing
- rotatable local-process credentials
- SQLite queue
- preview and PDF capture
- Windows printer enumeration and submission
- signed checksums, unsigned executable

## Candidate 0.2

Only after issue evidence and repeatable hardware tests:

- bounded retention and cleanup command
- richer printer capability diagnostics
- optional confirmation UI for new physical printer mappings
- Windows ARM64 build
- documented MSI or MSIX packaging path

## Explicitly later or never

- macOS or Linux backend without maintainers and real devices
- raw thermal printer languages
- cloud relay
- fleet management
- user directories, quotas, or billing
- driver installation
- automatic retry of interrupted physical submissions
